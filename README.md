# Student Management System

A console-based Student Management System developed using Core Java.

## Features

- Add Student
- View Students
- Update Student
- Delete Student
- Duplicate Student ID validation
- Input validation
- File handling
- Store student records in a text file

## Technologies Used

- Java
- OOP
- ArrayList
- Collections
- File Handling
- Scanner
- Git
- GitHub

## Concepts Used

### 1. Object-Oriented Programming

- Class
- Object
- Constructor
- Encapsulation
- Methods
- Getters and Setters

### 2. Collections

The application uses `ArrayList<Student>` to store student records.

### 3. File Handling

Student data is stored in:

`students.txt`

The application loads the existing student records when it starts.

### 4. Input Validation

The application validates:

- Student ID
- Age
- Marks
- Student name
- Course
- Menu choice
